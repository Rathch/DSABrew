# PDF/UA Export Contract

**Feature**: 001-dsa-brew-renderer  
**Implementation**: `web/src/pdf-export.ts`, `web/src/pdf-accessibility-tree.ts`, `web/src/pdf-lib-writer.ts`

## Overview

**PDF speichern** produces a **PDF/UA-1 oriented tagged PDF**:

- Visual layout: rasterized `.a4-page` preview (html2canvas) marked as **Artifact**
- Logical content: `StructTreeRoot` with standard structure types and **MCID**-linked invisible text
- Metadata: `Lang` de-DE, document `Title` (project title / first H1), `Author` / `Subject` / `Keywords` from impressum fields
- Fonts: embedded **Gentium Book Plus** (OFL) for tagged text — no Standard-14 shortcuts
- Links: internal `#anchor` and `https://` URL annotations

## Phased role mapping

### Phase 1 — core (implemented)

| HTML / selector | PDF role |
| --- | --- |
| `h1`–`h6` | `H1`–`H6` |
| `p`, `.page-number`, `.book-footer-title` | `P` |
| `ol` / `ul` + `li` | `L` / `LI` |
| `a[href]` (in TOC etc.) | `Link` (child of `LI`) |
| `nav.toc` | `TOC` (+ `H2`, lists) |

### Phase 2 — structured blocks (implemented)

| HTML / selector | PDF role |
| --- | --- |
| `table.dsa-md-table` | `Table` / `TR` / `TH` / `TD` |
| `footer.footnotes` | `Note` per entry |
| `aside.warnings` | `Sect` + `P` |
| `role="note"` / `.dsa-note`, `.dsa-roulbox`, `.dsa-diff` | `Note` |

### Phase 3 — DSA macros (implemented)

| HTML / selector | PDF role |
| --- | --- |
| `section.dsa-npc` | `Sect` + `H3`, `Figure` (portrait alt), `P` |
| `div.impressum-sheet` | `Sect` + `H1` / `Lbl` / `P` |
| `.dsa-chess`, `.dsa-difficulty-rating` | `Figure` (`aria-label`) |
| `.book-footer-strip` | `Sect` |

Decorative content (`aria-hidden`, leaders, GM frame caps, template overlays) is **not** in the structure tree; the page raster is an **Artifact**.

## Known limitations

- **Two-column reading order**: blocks are sorted left column then right column by horizontal position (heuristic). Perfect visual column order is not guaranteed for complex layouts.
- **Raster text**: visible typography remains in the background image; screen readers use the structure tree, not visual fonts (Andalus etc.).
- **Validation**: CI checks structure markers in generated bytes; full **veraPDF** UA-1 validation runs in the optional `pdf-ua-validate` workflow job.
